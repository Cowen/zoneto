## Critique Written

`specs/2026-03-14-model-critique-and-improvements.md`

Key findings:
1. **dev_approved is near-useless**: 99.7% of 20,690 labeled rows are "approved".
   The model predicts "approved" almost unconditionally. ROC-AUC 0.970 is an artifact
   of this imbalance, not genuine discriminative power.
2. **dev_appealed likely leaks status**: AUC 0.957 is suspiciously strong. The `status`
   column reflects the *current* state, including historical appeal outcomes. Applications
   from 2010 that resolved long ago appear with their final status — the model may be
   learning patterns in how statuses were historically recorded, not real filing-time
   predictors.
3. **dev_applications dataset is retired**: No new records. All scoring is retroactive.
4. **COA model too weak**: AUC 0.695 with only 2022–2023 data, one numeric feature.
   The 4 CoA panels (Toronto & East York, North York, Etobicoke York, Scarborough)
   have distinctly different approval dynamics — `planning_district` was completely
   unused.
5. **Uncalibrated probabilities**: HistGradientBoosting raw outputs don't correspond
   to empirical frequencies. A developer can't plug "0.84" into a financial model.
6. **`is_tlab_era` is redundant**: Perfectly correlated with `year_submitted >= 2017`.
7. **No permit issuance timeline model**: 161k cleared permits with application and
   issuance dates sit unused. The most operationally useful model (when will my permit
   be ready?) is entirely absent.

## Implementations

### 1. COA Feature Expansion
- `analytics/features.py`: Added `"planning_district"` to `COA_CAT_COLS`
- `analytics/features.py`: Added `"hearing_month"` to `COA_NUM_COLS`
- `analytics/enrich.py (enrich_coa)`: Extracts `hearing_month` from `hearing_date`;
  preserves `planning_district` through to the enriched parquet

### 2. Remove Redundant `is_tlab_era`
- `analytics/features.py`: Removed `"is_tlab_era"` from `DEV_NUM_COLS`
- `analytics/enrich.py (enrich_dev)`: Removed `is_tlab_era` column creation
  (`year_submitted` already captures the TLAB-era signal)

### 3. Model Calibration
- `analytics/train.py (train_source)`: Added `calibrate: bool = True` parameter
- When `calibrate=True` and `len(y) >= 20` and `not regressor`: wraps the unfitted
  pipeline in `CalibratedClassifierCV(cv=5, method='isotonic')` before fitting.
  The saved `.joblib` returns calibrated probabilities from `predict_proba`.

### 4. Permit Issuance Timeline Model
- `analytics/features.py`: Added `PERMIT_CAT_COLS` and `PERMIT_NUM_COLS`
- `analytics/enrich.py`: Added `enrich_permits(data_dir)` — reads `permits_cleared`
  parquet, computes `permit_issuance_days = issued_date - application_date`, drops
  non-positive values (data quality), writes `data/enriched/permits_cleared.parquet`
- `analytics/train.py (train_all)`: Optionally trains `permit_issuance_days.joblib`
  regressor when the enriched file exists (skip-if-absent design for backward compat)
- `analytics/score.py`: Added `_PERMIT_MODELS`, permit scoring to `score_all`
  (optional, skips if enriched file absent), and `permits_cleared` support in
  `score_one`
- `analytics/importance.py`: Added `permit_issuance_days` to `_MODEL_META`; handles
  `CalibratedClassifierCV` wrapper when computing builtin importance
- `cli.py`: Added `enrich_permits` call to the `enrich` command

### 5. Fix `evaluate_source` CV Capping
- Previously only capped `TimeSeriesSplit` cv at `n_samples - 1`; now also caps
  `KFold` and `StratifiedKFold` to prevent errors on small datasets
